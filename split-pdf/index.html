Split and extract PDF pages

Save a continuous page range from a PDF, or use Extract Pages for specific pages.

Open tool

How to split a PDF

Choose an unencrypted PDF. Enter the first and last page of the range, using the displayed document page numbers. Select Split PDF, then download and open the result.

Can I select pages that are not next to each other?

Use Extract Pages on the dashboard. Enter numbers and ranges such as 1,3,5-7. Only pages within the document are accepted.

Privacy and limits

The document is processed in this browser. PDF contents are not uploaded by the app. The file limit is 100 MB; complex files may need more memory than the browser can provide.

Office example

Extract the relevant pages from a supplier catalogue before sending a purchase request. Check that the result contains only the intended pages.

How to redact a PDF

Choose a PDF. Add a rectangle for each region to remove using a page number, X and Y coordinates, width and height. Coordinates are in PDF points from the bottom-left of the page. Run Apply Redactions and review every output page before sharing.

Why black boxes alone are not enough

Drawing a black rectangle over an existing PDF can leave the text underneath extractable. This tool instead renders pages, paints the selected regions black and creates a new image-only PDF. It does not copy original page content streams, attachments or metadata.

What changes in the output?

All pages become images. Searchable text, links, forms and accessibility structure are lost. The file can become larger. Cropping is different: it hides margins and is not a substitute for redaction.

Review is essential

The tool cannot identify confidential information for you. Confirm the rectangle fully covers the intended content, inspect all pages, and check that sensitive information does not appear elsewhere.

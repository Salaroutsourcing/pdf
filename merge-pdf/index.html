Combine contracts, invoices or reports into one PDF without sending document contents to a server.

Open tool

How to merge PDFs

Choose two or more unencrypted PDFs. Drag the files into the required order, choose the output page size if needed, then select Merge PDFs. Download the result and check the page count and order before sharing.

What happens to my files?

Merging runs in this browser using PDF-lib. The application does not upload PDF contents. Original files are unchanged; the output is a separate download.

Limits and document features

Each file can be up to 100 MB and each selection up to 200 MB. Complex PDFs may exceed available memory. Check forms, links, bookmarks and signatures after merging; this tool does not promise preservation of all interactive features.

Office example

Put a cover letter first, a proposal second and supporting invoices last. Use a consistent filename such as project-proposal.pdf after reviewing the download.

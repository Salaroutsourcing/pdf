Compress scanned PDFs

Create an image-only PDF with adjustable image quality and resolution. Compression is not lossless and may increase file size.

Open tool

How compression works

Each page is rendered as an image and embedded in a new PDF. Choose an image quality and resolution, run Compress PDF, and compare the reported output size with the original. Physical page dimensions are preserved.

What will I lose?

Selectable text, forms, links and original document structure are lost. Keep your original when these features matter. For a text-heavy PDF, the original may already be smaller than the image-only output.

What should I check?

Open the output and inspect small text, stamps, diagrams and signatures at normal reading size. If the result is larger or less readable, keep the original or try a different setting.

Office example

Try compression on scanned receipts for an email attachment. Avoid this workflow for accessible documents or forms that recipients need to fill in.
